How to

Turn a spoken draft into a cleaner message

Speak naturally, then let a saved instruction tidy your transcript. Dictidy combines local speech recognition with optional AI cleanup and pastes the result where you are writing.

Use the action that matches your intent

Dictate produces a transcript without an extra rewriting step. Dictate + Clean transcribes locally and then asks your selected language model to remove verbal clutter and improve the text. You choose which action to run.

Cleanup is designed to remove fillers, repetition, and rough punctuation while preserving your meaning. Results depend on the recording, model, and instructions. Always review names, numbers, and commitments before sending.

An illustrative example

Spoken draft: “Um, could you, could you send the revised agenda before Thursday? I want to check the timing before we share it.”

Possible cleanup: “Could you send the revised agenda before Thursday? I want to check the timing before we share it.”

Illustrative output, not a guarantee or a measured accuracy result.

Set it up once

  1. Install Dictidy and complete the setup wizard. Download the local speech model and grant Microphone and Accessibility permissions.
  2. Add your Anthropic or OpenAI API key and choose a rewrite model. Provider usage is billed separately.
  3. Choose a comfortable Dictate + Clean shortcut in Settings.
  4. Place your cursor in a text field, press the shortcut, speak, then press it again to stop.
  5. Review the cleaned-up text that Dictidy pastes into the field.

Keep your voice, or ask for a larger rewrite

The built-in Auto Clean instruction is intended for a light edit. Rewrite allows more changes to wording and structure. In Settings → Instructions, you can edit a prompt or create a new instruction, then give it its own model and shortcut.

For example, ask for a brief project update that preserves all dates and names. Be specific about what should stay unchanged. Cleanup is an editing aid, so read the result before using it.

Clean up text you already have

You can select a draft in most apps and press Shift-Command-R for Auto Clean, or choose an instruction from the menu bar. Dictidy replaces the selection in place. This works with text you typed or dictated elsewhere, as long as the field supports standard copy and paste.

Where the text goes

Your audio stays on your Mac. Cleanup sends the resulting transcript to Anthropic or OpenAI using your key. It needs internet access and incurs provider usage charges; it does not run locally. For offline transcription with no provider key, choose Dictate. Read the privacy details and usage guide.

Get started with Dictidy

Download the app and follow the installation guide. You can start with local dictation and add rewriting when you want it.
