Start with Apple if you need basic voice typing

Apple Dictation is already part of macOS. Check the text under Dictation in Keyboard settings to see how your voice input is processed. Apple also offers separate Writing Tools for rewriting on supported configurations; those should not be confused with the Dictation feature itself.

Choose Dictidy for local dictation and configurable rewriting

Dictidy is a good fit if you want an inspectable Mac app with a free prebuilt download. Use Dictate to enter text without a provider account. Use Dictate + Clean or rewrite selected text when you want a language model to edit the wording.

Those editing actions require your Anthropic or OpenAI API key. Text goes to the provider, internet access is required, and usage is charged separately. There is no Dictidy subscription. You will need an Apple Silicon Mac, macOS 13.3+, and about 1.6 GB for the speech model. Review the first-open instructions for the self-signed app.

Try the other free plans on their own merits

superwhisper’s free local dictation is a continuing option, not just a trial. Wispr Flow’s free allowance can be enough for lighter use. A paid feature set does not make the free portion unhelpful: match it to how often you dictate and whether you need AI cleanup.

What about open-source alternatives?

VoiceInk provides source code you can build yourself; its packaged app is sold separately. That is a different tradeoff from a free prebuilt download. See our open-source guide for a closer look.

Before choosing, test a short email in your usual text field. Check the result, decide what can leave your device, and account for both software and API costs.
