Know where your words go

Local speech.
Your choice of AI.

Dictidy has no account system and sends no app telemetry. Its code is open for anyone to inspect.

AI cleanup is a separate, online step. You decide which provider and model handle your text.

Read the privacy policy →
  • Audio stays on your Mac.Whisper transcribes locally. Dictidy keeps recordings in memory and does not save audio files.
  • Rewriting sends text to your provider.Selected text or a transcript, plus your instructions, goes directly to Anthropic or OpenAI. That provider’s data policies apply.
  • API keys stay in macOS Keychain.Each key is used only with its respective provider. You never enter keys on this website.
  • You control local history.History is on by default and stores text locally as plain-text JSON. Turn it off to stop saving new entries; clear history to delete saved entries.

Before you install: Dictidy is self-signed and is not notarized by Apple. macOS will show a first-open security warning. Read the installation guide before approving it.

  1. Download and open Dictidy.

    Unzip the download and move Dictidy.app to Applications. Follow the installation guide for the macOS first-open prompt.

  2. Follow the setup wizard.

    Grant Accessibility access so Dictidy can copy and paste in your apps, then quit and relaunch when prompted. Dictidy lives in the menu bar.

  3. Choose voice, rewriting, or both.

    For dictation, download the speech model and grant Microphone access. For cleanup or rewriting, add an Anthropic or OpenAI API key and select a model.

  4. Make it yours.

    Check your shortcuts, try Auto Clean, and tune your instructions. Use Check for Updates from the menu to keep the app current.

Good questions

A few things
before you download.

More setup help is in the documentation.

Is Dictidy really free?

Yes. The app and local dictation are free and open source. AI cleanup and rewriting require your own Anthropic or OpenAI API key, and you pay that provider’s usage charges. No Dictidy account or subscription is required.

Can I use it completely offline?

Raw Dictate works offline after you download the Whisper speech model. Dictate + Clean and rewriting selected text require an internet connection and a configured provider API key. Dictidy does not currently offer local AI rewriting.

Does my ChatGPT or Claude subscription cover rewriting?

A consumer chat subscription does not supply the API access Dictidy needs. Create an API key with Anthropic or OpenAI and set up that provider’s API billing separately. Use the provider’s account controls to manage your spending.

Will it work in my apps?

Dictidy uses macOS copy and paste automation, so it works in many standard text fields in apps such as Mail, Slack, Notes, browsers, and editors. App-specific text controls can behave differently. If a paste misses its target, use Copy Last Text or Paste Last Text to recover the result.

Can I dictate long meetings?

Dictidy is designed for short dictation at your cursor, not meeting recording. A recording automatically stops after five minutes. You can start another recording whenever you need one.

Does it support Intel Macs, Windows, or phones?

No. Dictidy currently supports Apple Silicon Macs running macOS 13.3 or later. There are no Intel, Windows, Linux, iOS, or Android builds.

What gets saved?

Dictidy does not save audio recordings. History is on by default and keeps up to 100 text entries locally. You can disable new history entries and clear existing ones in Settings. The latest output also stays available until you quit or clear history. See the privacy policy for details.

How does it compare with other dictation apps?

Dictidy suits Mac users who want a free, open-source app, local transcription, and control over AI models and prompts. Other apps may offer easier managed billing, mobile support, or local AI cleanup. Our comparison guides explain the tradeoffs.
