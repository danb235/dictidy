What you can do with Dictidy

Press your dictation shortcut, speak, then press it again. Dictidy transcribes locally with Whisper large-v3-turbo and pastes the text at your cursor. It works with most standard text fields that support copy and paste.

You can also select existing text and apply a saved rewrite instruction. Each instruction can have its own prompt, model, and shortcut. Dictate + Clean combines local transcription with that rewriting step.

Open source does not mean every feature runs locally

Dictidy keeps speech recognition on your Mac. Rewriting and cleanup send text to your chosen Anthropic or OpenAI model using your API key. The provider bills that usage. API keys are stored in the macOS Keychain; optional history is stored locally. The app sends no telemetry. See the privacy policy for the complete distinction.

Public source makes inspection possible; it is not proof that a particular build has been independently audited. Review the source, dependencies, release process, and the permissions an app requests according to your needs.

When another project may fit

VoiceInk provides a different set of dictation workflows and also advertises selected-text rewriting. Its source-build path and paid distribution may suit you. whisper.cpp is useful if you want the underlying engine for a project or custom tool, rather than a complete menu-bar app.

Check the project’s actual license before reusing or distributing code. An app’s open-source license and the terms for bundled models or external services can differ.

Try Dictidy without compiling

Download the app, move it to Applications, and follow setup. You need an Apple Silicon Mac with macOS 13.3 or later and roughly 1.6 GB for the speech model. The release is self-signed and not notarized; macOS requires first-open approval. Local dictation works without an API key after setup.

Get started with Dictidy

Download the app and follow the installation guide. You can start with local dictation and add rewriting when you want it.
