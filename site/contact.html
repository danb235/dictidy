Dictidy is maintained in the open on GitHub. Here is where to get help and share feedback.

Installation and setup

The README covers first launch, macOS permissions, the speech-model download and connecting your API keys.

Read the installation guide

Bugs and feature requests

Search existing issues, or open one with your Dictidy version, macOS version and steps to reproduce the problem. GitHub issues are public. Remove API keys, personal information and sensitive text from screenshots and reports.

Visit GitHub issues

Security vulnerabilities

Report security problems privately through GitHub’s vulnerability reporting flow. Do not post a public issue describing an unpatched vulnerability.

Report a vulnerability privately

Read the security policy

Maintainer and privacy questions

The project maintainer is @danb235 on GitHub. Visit that profile for the maintainer’s published contact options. General questions about the app’s data handling can also be raised as a GitHub issue without including private information.

The project currently publishes GitHub contact channels, not a dedicated support email or postal address. See the privacy policy for how audio, rewrite text and local history are handled.
