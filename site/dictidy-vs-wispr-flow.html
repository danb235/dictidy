Local audio, with a separate choice for rewriting

Dictidy’s Dictate action transcribes on your Mac and pastes the result at your cursor. It needs no API key and works offline after the speech model download.

Dictate + Clean adds a separate step: it sends the transcript to Anthropic or OpenAI using your API key. Rewriting selected text uses the same provider path. Those actions need internet access and incur provider charges. Dictidy has no telemetry, but choosing a cloud rewrite is still a choice to send text to that provider. Read the data-flow details.

Both apps can work with text you already wrote

Rewriting is not exclusive to Dictidy: Wispr documents selected-text Transforms. Dictidy’s approach is to give each saved instruction its own prompt, optional model choice, and keyboard shortcut. You can use a light cleanup instruction for a message and another instruction for a more substantial rewrite.

Which should you try?

Try Dictidy if you use a compatible Mac, want to inspect the source, and prefer local transcription with direct control over rewrite providers. Allow time for the roughly 1.6 GB speech model download. The app is self-signed and not notarized, so follow the installation instructions when macOS asks you to approve it.

Consider Wispr Flow if cross-platform availability and a hosted workflow matter more to you. Its privacy controls and cloud processing deserve a direct review rather than a blanket “private” or “not private” label.
